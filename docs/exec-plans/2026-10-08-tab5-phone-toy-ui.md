## 1. 목표 (Goal)

Tab5 전화기의 모든 화면을 "장난감 전화기 + 귀여운 캐릭터들" 모양으로 바꾼다. 통화 기능·소리·버튼 자리는 그대로 두고 겉모습만 바꾼다. 완료 판정은 §6.

- 사용자 요청(2026-10-08): "UI를 키치한 폰화면 같은 느낌으로" → 방향 선택 "장난감 전화기이지만, 귀여운 캐릭터들이 있는 구성" → 시안 승인 "좋네. 멋져" + 수정 한 가지("음량 표시가 Wi-Fi 같다 — 스피커 옆에 막대") → "최종 반영해줘".
- 시안: <https://claude.ai/artifact/XdBkmmmCxTaKcpdAui2ZGn> (대기·전화 옴·통화 중·캐릭터). 규칙의 정본: `docs/design/README.md` §5.

## 4. 전제·제약

- 화면은 1280×720 RGB565 버퍼 한 장에 합성해 PPA 로 한 번에 내보낸다(약 60~80ms). 그리기는 화면 태스크 하나.
- 음량만 바뀌면 `ui::draw_volume` 이 음량 칸만 다시 그린다 → 음량 칸의 판은 다른 것과 겹치지 않아야 한다.
- 이 맥미니에는 `main/secrets.h` 가 없다(맥북에만 있다) → 여기서는 예시 파일로 **컴파일만** 확인할 수 있고, 올릴 수 있는 빌드는 만들 수 없다.
- 작업 시점에 연결된 2번 기기는 약 8초 주기로 재부팅을 반복하고 있었다(배터리를 낀 채 맥 포트에 꽂았을 때의 과전류 차단과 같은 모양 — `docs/ARRIVAL-CHECKLIST.md`, 원인 미확정). 1번 기기는 연결되어 있지 않았다.
- devsync 가 5분마다 자동 커밋·푸시한다 → 작업은 `wip/toy-ui` 브랜치에서 했다.

#### 맥북에서 1번 기기에 올리는 순서
```
cd ~/tab5-toy-phone && git pull                                   # main (이미 받아 뒀다. 그 뒤 바뀐 것이 있으면 받는다)
cd firmware/tab5_phone && source ~/esp/esp-idf-5.5.4/export.sh

PORT=$(python3 tools/phone_ctl.py port 1) && echo "1번 포트: $PORT"
python -m esptool --chip esp32p4 -p "$PORT" read_mac 2>&1 | grep -i "aa:bb:cc:dd:ee:01"   # 대상이 1번인지
mkdir -p ../../backups && python -m esptool --chip esp32p4 -p "$PORT" -b 921600 read_flash 0x0 0x320000 ../../backups/tab5-1_before-toy_$(date +%F)_0x0-0x320000.bin   # 백업, 약 15초

```
