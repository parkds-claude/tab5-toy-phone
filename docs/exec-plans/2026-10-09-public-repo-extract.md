# 공개 리포 분리 — 전화기 트랙을 tab5-toy-phone 으로

- **작성일**: 2026-10-09 (갱신 2026-10-11)
- **상태**: done

## 목표
비공개 작업 저장소에서 전화기 관련 코드·문서만 떼어 공개 리포로 낸다.

## 비목표
전화기가 아닌 다른 트랙. 일일 작업 기록. 백업 바이너리(UIFlow2 포함 — 재배포 불가). 빌드 결과물(토큰이 들어 있다).

## 가져온 것
`firmware/tab5_phone`, `firmware/stackchan_phone`, `server/phone_*`·`tests/test_phone_*`·`deploy/`, `docs/design`, `docs/glossary`, `docs/exec-plans` 의 전화기 문서, 주아체 글꼴(OFL 원문 동봉).

## 자리표시자로 바꾼 것
기기 MAC(모든 표기) → `AA:BB:CC:DD:EE:01~04`, 홈 경로 → `~`, 교환기 호스트 → `phone.example.com`, launchd 라벨 → `com.example.…`, 사설 VPN 주소 → `100.64.0.x`, 터널 ID → 0, 같은 서버의 공용 터널 이름 → `maintunnel`.
시험이 이 값을 고정하므로 시험 파일도 같은 규칙으로 바뀌었다. 문서 속 명령·기록에 보이는 주소와 이름은 그래서 실제 값이 아니다.

## 검증
- 새로 내려받은 사본에서: 교환기 pytest 481, 도구 pytest 263, 스택짱 도구 pytest 23(littlefs-python 을 깔면 이중 부팅 시험까지 46), 맥 C++ 시험 16종 + 스택짱 화면 144, Tab5·스택짱 펌웨어 빌드(경고 0).
- 잔존 검사: 식별 값의 무늬(기기 MAC 의 모든 표기·호스트·계정 경로·메일·열쇠 꼴)와 실제 비밀 값 대조 0건.
