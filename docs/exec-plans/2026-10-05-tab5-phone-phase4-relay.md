## 한눈에 보기 (사용자용)

- **지금**: 두 전화기는 맥북과 같은 Wi-Fi 에 있을 때만 통화된다(맥북이 교환기). 다른 방에서 통화하면 약하게 "삐—" 하고 울린다. 소리 크기는 못 바꾼다.
- **이 묶음이 끝나면**: ① 약한 울림(하울링)이 사라진다 — 작은 목소리를 키워 주는 기능은 그대로 ② 화면에 **소리 작게/크게** 버튼이 생기고 껐다 켜도 기억한다 ③ 교환기가 사무실 **맥미니**로 옮겨져, 집 Wi-Fi 의 전화기와 사무실 Wi-Fi 의 전화기가 인터넷으로 통화한다(암호화된 연결).
- **그다음**: 화면을 "키치한 애니메이션" 스타일로 다시 디자인한다 — 방향 3가지를 그림으로 보여 드리고 고르신 뒤 만든다.

## 과제

1. (끝) 수신 무음 감시·미룬 지적 — 검증된 패치 T9·T10 적용(`d03959c`·`ad7be1d`).
2. 하울링 수정 — 두 기기 고리 모형 시험 먼저(`wip/howl`).
3. 음량 버튼 — 순수 헤더 + 화면 + NVS + 시리얼 명령(`wip/vol`).
4. 펌웨어 `wss://` — 인증서·메모리·스택·시간 제한(`wip/net`).
5. 서버 — 종료 훅, `server/deploy/phone_relay_prod.sh`, `server/tools/phone_token_rotate.py`, 터널을 거친 통화 확인 도구.
6. 합치기 → 검수 → 맥미니에 교환기·터널 올리기 → 가짜 기기로 터널 통화 확인 → 토큰 교체 → 빌드 → 두 기기에 올리기(2번 → 1번, 스피커 끈 채 점검) → 스피커 켜기.
7. 사용자: 다른 방 통화(하울링·음량 버튼), 한 대를 휴대폰 핫스팟이나 집 Wi-Fi 에 물려 서로 다른 망 통화.
8. 문서(README·설계서 §5·§8)·Bot Dashboard 등록·맥북 교환기 끄기.
